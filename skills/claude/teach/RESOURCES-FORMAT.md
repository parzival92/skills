# RESOURCES.md Format

`RESOURCES.md` is the curated set of trusted sources for a teaching topic.

## Structure

```md
# {Topic} Resources

## Knowledge

- [Resource title](https://example.com)
  What it covers. Use for: when to reach for it.

## Wisdom (Communities)

- [Community name](https://example.com)
  What it is useful for.

## Gaps

- {Missing resource area}
```

## Rules

- Prefer high-trust sources.
- Annotate every entry.
- Group resources by knowledge and wisdom.
- Surface gaps explicitly.
- Remove resources that turn out to be weak or off-mission.
- Record community preferences.
