# Mode: recap

Weekly synthesis: turn seven days of briefs into trends, and resurface what is fading.

## Workflow

1. **Load the week.** Read the last 7 files in `digests/`, `profile.md`, and the qbank
   entries drilled this week. Completion: you can list every item delivered this week.

2. **Synthesize.** Write the recap with:
   - **Trends** — 3–5 threads that connect multiple items this week, each with the items
     that support it (a trend needs ≥2 items; don't invent one from a single story).
   - **Biggest story** — the one item to bring up in an interview this week, and how.
   - **Drill health** — pass rate this week and the weak areas still open.
   - **Next week** — 2–3 topics worth a `deep`, chosen from trends + weak areas.
   Completion: every trend cites its supporting items by title.

3. **Spaced recall.** Ask 3 rapid-fire questions from qbank entries added 7–30 days ago,
   one at a time, graded briefly (right / missing / model answer). Skip with a note when
   the qbank has no entries that old yet.
   Completion: 3 asked (or skip noted) and their `last-drilled` fields updated.

4. **Persist.** Write the recap to `digests/recap-<today>.md`.
   Completion: file on disk.
