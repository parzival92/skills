# Learning Record Format

Learning records live in `./learning-records/` and use sequential numbering: `0001-slug.md`, `0002-slug.md`, etc. Create the directory lazily.

They capture demonstrated understanding, stated prior knowledge, corrected misconceptions, and mission shifts that should steer future teaching.

## Template

```md
# {Short title}

{1-3 sentences describing what was learned or established and why it matters for future sessions.}
```

## When To Write One

- The user demonstrated genuine understanding.
- The user disclosed prior knowledge.
- A misconception was corrected.
- The mission shifted in response to learning.

## What Not To Record

- Material that was merely covered.
- Anything already captured tersely in a glossary.
- Session-by-session activity logs.
